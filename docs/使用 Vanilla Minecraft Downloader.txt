使用 Vanilla Minecraft Downloader

约定
为了称呼方便，以下会将其简称为 VMD 下载器。

下载 VMD 下载器
请先从 Github 界面（https://github.com/GetSoftwares/Vanilla-Minecraft-Downloader/releases）中下载对应处理器架构的 VMD 下载器。
· 对于 amd64 用户，请下载 -amd64.zip 结尾的文件。
· 对于 x86 用户，请下载 -x86.zip 结尾的文件。
· 对于 arm64 用户：
  · 如果你正在使用 Windows 11（内部版本号 22000 或更高版本），那么请下载 -amd64.zip 结尾的文件。
  · 如果你正在使用 Windows 10 on ARM，那么请下载 -x86.zip 结尾的文件，因为这个版本的 Windows 10 不支持运行 amd64 架构的应用程序。
  · 每个不同处理器架构的版本均包含了不同架构的 aria2 来处理下载，并且均会自动判断要使用哪个处理器架构的 aria2。
· 对于 arm 用户，请下载 -x86.zip 结尾的文件。
解压下载下来的文件后，可双击直接运行里面的 EXE 文件，已打包好所有用到的程序（aria2、Python 3.14 和 requests 模块），无需安装依赖项即可使用。

使用
在首次使用时（或者配置文件不存在时），VMD 下载器会提示你是否要添加默认的 Minecraft 文件夹（%APPDATA%\.minecraft）。这个步骤是可选的，你可以不添加它。
配置文件会被保存在 %APPDATA%\Vanilla Minecraft Downloader\config.json。
随后，你将会进入到程序首页（主界面），其中可以下载版本、Minecraft 文件夹管理、从其他启动器导入文件夹、调整设置等。
各部分的操作详见下方说明。

下载版本
在主界面输入 1 并按回车即可进入下载界面，可以选择下载最新正式版、最新快照版和指定版本。
以下是下载界面中选项的含义：
    最新正式版 - 下载最新的正式版，即版本列表中的 latest.release。
    最新快照版 - 下载最新的快照版，即版本列表中的 latest.snapshot。请注意可以修改 Minecraft 文件夹设置来不下载愚人节版本的快照。
    指定版本 - 输入版本号（例如，1.21.11、26.4-snapshot-1 或者 13w16a）并下载指定版本。
    强制刷新版本列表 - 忽视缓存，强制从官方源拉取版本列表。当版本列表未能正常自动更新时非常有用。
    退出下载 - 退出下载界面，不下载 Minecraft。
最新正式版和最新快照版还会各自显示它们所指的版本号。
当选定最新正式版、最新快照版或指定版本后，VMD 下载器将开始下载指定版本的 Minecraft，并根据下载器设置来进行自动重试和哈希检查。
当出现“版本 <VERSION> 下载完毕！”（其中 <VERSION> 需要替换为实际的版本号，例如 1.21.11、26.4-snapshot-1 或者 13w16a）时，说明下载成功，你可以用任意启动器来启动这个版本。
当下载过程中出现了任何失败时，如果开启了自动重试，那么 VMD 下载器将会尝试再次下载，最多 5 次（包括初始下载的一次）。当 5 次尝试全部耗尽但仍下载失败，则会结束下载。

Minecraft 文件夹管理
在主界面输入 2 并按回车即可进入 Minecraft 文件夹管理界面。
VMD 下载器首先会列出全部可用的 Minecraft 文件夹，此时你需要输入每个文件夹前面的数字，例如：
    [1] %APPDATA%\.minecraft
则需要输入 1 并按回车来选中 %APPDATA%\.minecraft 文件夹。
对于默认文件夹会在文件夹后面添加“（默认）”来表示这是当前的默认文件夹，例如：
    [1] %APPDATA%\.minecraft（默认）
同时，VMD 下载器也会列出下列操作：
    添加一个文件夹 - 添加一个其他路径的 Minecraft 文件夹。
    设置默认文件夹 - 选择一个文件夹并将其设为默认文件夹。
    更改当前文件夹的设置 - 更改当前文件夹设置的快速入口。
    更改当前文件夹的路径 - 更改当前文件夹路径的快速入口。
    删除一个文件夹 - 选择一个文件夹并经过二次确认后来删除。
    退出 - 不执行任何操作并退出文件夹管理界面。
通过选择一个文件夹进行管理
在选择一个文件夹后，VMD 会显示一系列选项，显示你可以对该文件夹进行的操作。
以下是可以进行的操作的含义：
    更改当前文件夹的设置 - 更改当前文件夹的设置。
    更改文件夹的路径 - 将当前的文件夹改为另一个路径的文件夹。
    设为默认文件夹 - 将当前的文件夹设置为默认文件夹。
    删除文件夹 - 从文件夹列表中移除当前文件夹。这将不会实际删除所指向的文件夹，而只是移除这个文件夹条目。
    退出操作 - 不进行任何操作并退出管理界面。
当删除文件夹时，VMD 下载器会要求你确认是否确实要删除当前文件夹。当输入 y/yes/是（不区分大小写）时 VMD 下载器才会删除当前文件夹。这是为了防止无意删除文件夹而设置的。
当没有任何可用的文件夹时，VMD 下载器会提示你需要先添加一个文件夹才能继续操作。此时你需要在该界面中输入 A（大小写不敏感，下同）并按回车来添加一个 Minecraft 文件夹。
要输入的文件夹路径必须是一个文件夹，当不是文件夹时（不存在或者是文件）会给出错误提示。
当添加文件夹前没有任何 Minecraft 文件夹时，那么添加完后当前文件夹就会被设置为默认文件夹。
在选择文件夹后输入 1 并按回车可调整当前文件夹（即默认文件夹）的设置，可设置项如下：
    多版本隔离 - 将多个版本隔离到 <Minecraft 文件夹>\versions\<版本> 里，有助于避免版本冲突或存档损坏。默认值是根据当前文件夹中是否存在 versions 文件夹来确定的。
    下载愚人节版本 - 是否下载愚人节版本。由于愚人节版本在版本列表中属于快照，所以当愚人节版本发布时会将最新快照设为这个版本。此设置项可以让你不下载愚人节快照而是最新的非愚人节快照（按时间排序）。
    退出更改 - 不更改任何设置项并退出更改文件夹设置。
这些设置仅对当前文件夹有效。要想更改其他文件夹的设置，请更改默认文件夹后再进行设置。具体操作请参见本节开头。
通过选择一个操作进行管理
你也可以通过文件夹列表下面的操作列表来管理文件夹。要执行这些操作，你需要首先输入字母而不是数字。
当你要添加一个文件夹时，在该界面中输入 A 并回车，VMD 下载器会要求你输入要添加的文件夹的路径。你可以手动输入，也可以拖拽路径，可使用环境变量，VMD 下载器会自动处理路径。
当你要设置默认文件夹时，在该界面中输入 B 并回车，然后输入要设为默认文件夹的数字序号，即可将所选定的文件夹设置为默认文件夹。
当你要更改当前文件夹的设置时（这是修改当前文件夹设置的快速入口），在该界面中输入 C 并回车，即可进入修改文件夹设置界面。可修改详情参见“通过选择一个文件夹进行管理”中关于调整当前文件夹设置的部分。
当你要更改当前文件夹的路径时（这是修改当前文件夹路径的快速入口），在该界面中输入 D 并回车，然后输入一个新的文件夹路径，即可更改当前文件夹的路径。
当你要删除一个文件夹时，在该界面中输入 E 并回车，然后输入要删除的文件夹的数字序号，并进行再次确认后即可删除该文件夹。
当不需要进行管理时，在该界面中输入 F 并回车即可退出文件夹管理。
注意
试图输入任何形式的现有文件夹（例如环境变量和相对路径）都将会失败。VMD 下载器不允许重复出现一个文件夹路径。

调整下载器设置
在主界面输入 3 并按回车即可进入下载器设置界面，可以修改下载器的设置。这些设置是全局性的，在任何文件夹中都适用。
以下是设置界面中选项的含义：
    检查文件哈希 - 检查下载的文件的 SHA-1 值是否与文件中给出的 SHA-1 值匹配。默认为开。
    自动重试 - 在下载失败时（例如文件大小不对应或者哈希校验失败）自动重新下载，最多五次（含初始下载所用的一次）。默认为开。
    显示下载日志 - 显示下载的整个过程，包括当前正在下载的内容、将要下载的内容和下载过程信息等。默认为开。
    导入时设置默认文件夹 - 从其他启动器导入文件夹时，将启动器的默认文件夹设为下载器的默认文件夹。默认为自动。
    调试 - 输出调试信息以便于进行调试或排查问题。默认为关。
    恢复默认设置 - 将所有设置重置为各自的默认值。
    退出 - 不更改设置并退出设置界面。
当选定“检查文件哈希”、“自动重试”、“显示下载日志”、“导入时设置默认文件夹”或“调试”后将会立即修改设置，更改立即生效。当选定“恢复默认设置”时，需再次确认后才会重置为默认设置。
建议保持 VMD 下载器默认的设置以获得更好的下载体验。

从其他启动器导入文件夹
在主界面输入 4 并按回车即可进入从其他启动器导入文件夹界面，可以从 HMCL、PCL2（含 PCL2-CE）等启动器来导入文件夹。当你不想要手动输入启动器中的文件夹时非常有用。
注意，当前只实现了 HMCL 的文件夹导入，尚未实现其他启动器的文件夹导入。
当你要从 HMCL 启动器导入 Minecraft 文件夹时，请在导入界面中输入 1，然后输入或拖拽 HMCL 启动器的路径（可以是 HMCL 可执行文件的位置，也可以是 HMCL 启动器所在的文件夹），即可自动导入 HMCL 的 Minecraft 文件夹。
当将要导入的文件夹路径存在于下载器的文件夹列表中时，VMD 下载器不会重复导入该文件夹。
当你设置了“导入时设置默认文件夹”选项，会根据选项值来执行对应操作：
· 当选项值为“自动”时，如果下载器没有默认文件夹的话，就会将启动器的默认文件夹设置为下载器的默认文件夹，否则保留下载器的默认文件夹。
· 当选项值为“开”时，总是将启动器的默认文件夹设置为下载器的默认文件夹。
· 当选项值为“关”时，不会将启动器的默认文件夹设置为下载器的默认文件夹。

异常处理
当当前文件夹对应的条目不存在时（通常是从外部修改了配置文件，但没有同时更改 default_folder_uuid 导致的），VMD 下载器就会要求你重新设置一个默认文件夹以确保任何对当前文件夹的操作都能够继续。
此时，你需要在主界面中输入 2 并回车来进入文件夹管理界面，选中一个文件夹并将其设为默认，或者（如果没有任何 Minecraft 文件夹）在文件夹管理界面中输入 B 并输入你咬舌为默认文件夹的数字序号来将其设置为默认文件夹。
当配置文件加载失败时，VMD 下载器会重新生成一份配置文件，并覆盖现有的配置文件。

局限性
当前 VMD 下载器只支持 Windows 平台，不支持 Linux 和 macOS 平台。
VMD 下载器只能下载原版的 Minecraft，而没有除此以外的用途。
